# Text link button

`pattern: "text-link-button"` (stub: batch 4 item 6)

**Question it answers:** where do I go for more?

- **Use when:** a quiet way to move on: "See all stores →", "Definitions", a drill-through to detail.
- **Avoid when:** the main action of the page (use a filled button) or a link that only repeats the tabs.

## Design
- A button with no fill and no outline, text in `brandText` (4.5:1 on its background), an arrow or an underline on
  hover, alt text naming the target.

## Build (visual-method ladder)
- 1 native: a blank button with text, action Page navigation, Bookmark or Drill through.
- Template `actionButton.text-link-button`: **needs a Desktop-saved sample.** Make it on the Patterns page in Desktop,
  save, and run
  `pbik templates harvest`; until then build from the plain type's template and the layout's own keys.
