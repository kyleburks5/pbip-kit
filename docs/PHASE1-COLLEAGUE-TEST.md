# Colleague test (v1.7)

For someone who has never used the kit. They try it alone; you watch and write down where they get stuck. About an
hour. Made-up data only (the `pbik-walkthrough-inputs` folder beside the kit); never real data.

## Setup (you, before they arrive)

- A laptop with VS Code and GitHub Copilot (the main work environment) or Claude Code, Power BI Desktop and the kit.
- The made-up inputs and the stand-in team pack folder beside the kit, with the model already shared to it once (so
  this is a quick build with a model pack).
- Close any terminal. Don't explain the kit. Give them only the task list below.
- Have a timer and this page to fill in.

## Their task list (hand this over)

You're building a small Power BI report by chatting with the assistant. You never need a terminal. If you're unsure,
ask the assistant, not me.

1. Ask for an orders dashboard on the model *Example Big*, from the wireframe in *3 made-up wireframe* (give the
   assistant a copy when it asks). Choose the **quick build**.
2. Look at the plan picture. Change one thing you'd like different, then say OK.
3. Look at the result and its polish score.
4. Switch the report to live when the assistant asks. The live pick is in *2 made-up live pick*, standing in for
   Desktop. Then put it back on the made-up model.

## What to observe (you)

| # | Step | Time | Interactions | Where they hesitated (more than ~10 s) | What they asked | Needed a terminal or a path? | Notes |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | Ask, give the wireframe, choose quick | | | | | | |
| 2 | Plan picture, one change, OK | | | | | | |
| 3 | Result and score | | | | | | |
| 4 | Switch to live (pick, window with code) and back | | | | | | |

An interaction is one message they send or one approval window. Target: 3-4 for a quick build with a model pack.

Also note:

- Did they read the approval window before typing the code? Did they understand what *Yes* would do?
- Did the plan picture match what they expected to get? Did the result match the picture?
- Did the assistant ever show a path, command, slash command, ID or JSON? Quote it.
- Words they didn't understand, such as "synthetic", "contract", "bind", "pack" or "polish score".
- Anything they expected to happen that didn't.

## Afterwards

- Total time, the polish score, the interaction count, and any minutes they spent tidying it in Desktop.
- Their own words: the hardest moment, and what would have helped.
- Copy the table into design/reviews/ (no names: "colleague 1").
